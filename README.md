# Productive

A website that helps you stay on track your goals!

https://orangejuiceonntop.github.io/Productive/

![alt text](images/Readmeimage.png)

## Features

- A To-Do List (You can't check tasks)
    - Create new tasks by clicking the "Add" buttons or by pressing "Enter" on your keyboard
    - Tasks are saved locally so when you refresh or leave the site, it stays

- A Pomodoro Timer
    - Has 3 modes: 25 min focus, 5 min break, and 15 min break
    - Add/decrease minute buttons

- Motivational Quote Generator
    - New quote appears with every refresh

- A Notepad

- A Calendar
   - The current day is highlighted
   - You can see previous/upcoming months and years
