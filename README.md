# Productive

A website that helps you stay on track your goals!

![alt text](images/Readmeimage.png)

## Features

- A To-Do List (checking items doesn't work currently)
    - Create new tasks by clicking the "Add" buttons or by pressing "Enter" on your keyboard

- A Pomodoro Timer
    - Has 3 modes: 25 min focus, 5 min break, and 15 min break
    - Add/decrease minute buttons

- Motivational Quote Generator

- A Notepad

- A Calendar
